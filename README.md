# Task 4: Simple User-Management CRUD App

## Overview
A lightweight full‑stack example that demonstrates how to build a **CRUD** (Create‑Read‑Update‑Delete) web application using:
- **Node.js / Express** for a RESTful backend API (with CORS and JSON middleware).
- Plain **HTML, CSS, and JavaScript** for a static frontend that consumes the API via `fetch`.

The app lets you view a list of users, add new users, and delete existing users.
